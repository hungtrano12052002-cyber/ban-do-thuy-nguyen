BẢN ĐỒ SỐ THỦY NGUYÊN — MOBILE V6.4

Nâng cấp từ bộ V5 Cloud của bạn.

Điểm mới:
- Bản đồ đường phố rõ hơn và thêm lớp Vệ tinh / Sáng.
- Marker hình ghim-ngôi nhà, màu xanh = hoạt động, đỏ = ngừng hoạt động.
- Tự gom cụm marker khi thu nhỏ để bản đồ đỡ rối.
- Zoom từ mức 16 sẽ hiện nhãn tên cơ sở trực tiếp trên bản đồ.
- Chọn cơ sở sẽ bay/zoom mượt đến vị trí.
- Có chú giải trạng thái, thước tỷ lệ và cụm điều khiển bản đồ gọn hơn.
- Tối ưu giao diện mobile/iPhone, vẫn giữ Cloud/Supabase, thêm-sửa-xóa, tìm kiếm, dẫn đường và PWA.

CẬP NHẬT GITHUB PAGES:
1. Giải nén gói này.
2. Upload toàn bộ file/thư mục bên trong lên nhánh main của repo ban-do-thuy-nguyen, ghi đè file cũ.
3. Chờ GitHub Pages deploy.
4. Trên iPhone: đóng PWA cũ hoàn toàn rồi mở lại. Nếu vẫn thấy giao diện cũ, mở Safari vào website, tải lại trang rồi mở app lại.

Lưu ý: Chỉ các cơ sở có lat/lng hợp lệ mới hiện marker. Các link Google Maps không tự tạo marker nếu dữ liệu chưa có tọa độ.
